## English

### 🌟 Key Features & Capabilities

* **Responsive & Modern UI:** Built with Bootstrap 5 to deliver a seamless layout across desktop, tablet, and mobile devices.
* **Interactive Dark Mode:** Includes a custom pull-string lamp feature to toggle between Light and Dark themes dynamically.
* **Dynamic Shipping Calculator:** Estimates shipping costs in real time based on package weight (kg) and transport mode (Road, Air, Sea).
* **Cargo Tracking System:** Enables users to check package delivery statuses using unique tracking codes (e.g., `AZ123`).
* **Smooth Navigation:** Features smooth scrolling across main page sections (Home, Services, Calculator, Tracking).
* **Service Showcase & Metrics:** Displays core transport offerings alongside key company performance metrics.

## Azərbaycan Dili

### 🌟 Əsas Funksiyalar və İmkanlar

* **Responziv və Müasir İnterfeys:** Bootstrap 5 çərçivəsi sayəsində masaüstü, planşet və mobil cihazlarda tam uyğunlaşmış şəkildə çalışır.
* **İnteraktiv Tünd Rejim:** İnteraktiv lampa simgəsi və ipi vasitəsilə İşıqlı və Tünd rejimlər arasında dinamik keçid imkanı təqdim edir.
* **Dinamik Çatdırılma Kalkulyatoru:** Yükün çəkisi (kq) və daşınma növünə (Quru, Hava, Dəniz) əsasən anında təxmini qiyməti hesablayır.
* **Yük İzləmə Sistemi:** İzləmə kodları (məsələn: `AZ123`) vasitəsilə yükün anlıq statusunu ekranda nümayiş etdirir.
* **Rəvan Naviqasiya:** Səhifə bölmələri arasında yumşaq və rəvan keçid (Smooth Scroll) təmin edir.
* **Xidmət Kartları və Statistik Göstəricilər:** Logistika xidmətlərini və şirkətin əsas uğur göstəricilərini vizual olaraq təqdim edir.

## Türkçe

### 🌟 Temel Özellikler ve Yetenekler

* **Duyarlı ve Modern Arayüz:** Bootstrap 5 kullanılarak masaüstü, tablet ve mobil cihazlarda sorunsuz çalışacak şekilde tasarlanmıştır.
* **Etkileşimli Karanlık Mod:** Özel ipli lamba tasarımı ile Açık ve Koyu temalar arasında dinamik geçiş sağlar.
* **Dinamik Taşıma Ücreti Hesaplayıcı:** Kargo ağırlığı (kg) ve taşıma türüne (Kara, Hava, Deniz) göre anlık fiyat hesaplar.
* **Kargo Takip Sistemi:** Takip kodları (örnek: `AZ123`) kullanılarak gönderinin güncel durumunu görüntüler.
* **Pürüzsüz Gezinme:** Sayfa bölümleri arasında akıcı ve yumuşak geçiş (Smooth Scroll) sunar.
* **Hizmet Kartları ve İstatistikler:** Sunulan lojistik hizmetlerini ve şirket başarı göstergelerini görsel olarak sergiler.
